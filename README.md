# Hydro-Québec Peaks — a Home Screens plugin

Winter peak-demand events from Hydro-Québec open data (Crédit hivernal / Flex D) with what to do.

Install: Home Screens editor → Plugins → Install from URL…

```
https://github.com/tweetyboopdev2022-code/home-screens-hydro-peak/releases/latest/download/hydro-peak.tgz
```

Build: `npm install && npm run build`
